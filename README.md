# plugin-openclaw-to-harvestflow

npm client for HarvestFlow backend — provides an HTTP client and OpenClaw plugin tools for AI agent session data collection, curation, and review.

## Installation

```bash
npm install
npm run build
```

The `build` script compiles TypeScript to `dist/`. The `dist/` directory is required for the plugin to load (entry point defined in `package.json`).

## Configuration

Configure the client by passing a config object:

```typescript
{ baseUrl: string; apiKey?: string }
```

- `baseUrl` — points to the HarvestFlow backend (e.g., `http://localhost:3001`)
- `apiKey` — optional Bearer token for API authentication

## Usage

```typescript
import { HarvestFlowClient } from 'harvestflow-openclaw-extension';

const client = new HarvestFlowClient({ baseUrl: 'http://localhost:3001' });
const sessions = await client.getSessions({ status: 'raw' });
```

The client exposes methods for all HarvestFlow API endpoints: collector (scan/import), curator (evaluate), reviewer (approve/reject), and session management.

## Build Note

`dist/` is generated by `npm run build` and is required for the plugin to load. The entry point in `package.json` points to `dist/index.js`. After making changes to source files, always run `npm run build` before testing.
